# slogx

[![Go Reference](https://pkg.go.dev/badge/github.com/holedaemon/slogx.svg)](https://pkg.go.dev/github.com/holedaemon/slogx)

A set of extensions for the [log/slog](https://pkg.go.dev/log/slog) standard library introduced in [Go 1.21](https://go.dev/blog/slog). The context wrapper was adapted from [zikaeroh/ctxlog](https://github.com/zikaerog/ctxlog).
